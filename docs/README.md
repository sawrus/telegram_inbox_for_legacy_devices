## Docs as Code

Документация хранится в Git вместе с кодом. При изменении поведения, конфигурации или развёртывания обновляйте
соответствующую страницу и публичный README в том же изменении. Описывайте фактическое поведение, требования,
операционные ограничения и проверяемые команды; секреты и персональные данные не включайте.

Новые страницы размещайте по назначению в `docs/` и добавляйте в этот указатель. Используйте относительные ссылки,
рассматривайте документацию наравне с кодом при ревью и запускайте `make docs-check` вместе с остальными проверками.
Эта же проверка запускается в GitHub Actions при push и pull request.
Проверка обнаруживает отсутствующие локальные файлы в Markdown-ссылках, но не проверяет внешние ссылки, якоря или
точность текста; эти аспекты проверяются при ревью.
