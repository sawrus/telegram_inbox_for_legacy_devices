# Два чата на одном экране

## Цель

Пользователь может открыть основной экран и одновременно читать два Telegram-чата: один в левой панели, другой в
правой. Это помогает сравнивать или мониторить переписки на старых устройствах без SPA и WebSocket.

## Acceptance Criteria

- Основной маршрут `/` показывает левую и правую панели чатов без глобальной шапки и без толстой вертикальной разделительной линии.
- Каждая панель имеет закреплённую тонкую верхнюю панель только с dropdown выбора чата без отдельной текстовой метки `Чат`.
- Dropdown выбора чата в каждой панели имеет максимальную ширину `300px` на широких экранах и растягивается на всю ширину панели на узких экранах.
- Стартовые чаты берутся из `LEFT_CHAT_ID` и `RIGHT_CHAT_ID`, если URL не задаёт `left_chat_id` и `right_chat_id`.
- Старый маршрут `/chats/<id>` перенаправляет на основной экран с выбранным левым чатом.
- Сообщения показывают входящие и исходящие записи.
- Форматирование Telegram entities (жирный, курсив, код, цитаты и ссылки) отображается как безопасный HTML; исходный
  HTML-текст не интерпретируется, а небезопасные URL удаляются.
- Входящие сообщения выделены мягким полупрозрачным зелёным фоном и более крупным шрифтом.
- Исходящие сообщения отмечены как `Моё`, имеют светло-серый фон и сдвиг вправо на `20px`.
- Время сообщений отображается в часовом поясе `MESSAGE_TIMEZONE`, по умолчанию `Europe/Samara`.
- Смена dropdown сразу показывает сообщения выбранного чата.
- Левая и правая панели скроллятся независимо, а выбор чата остаётся закреплённым сверху.
- Страница сохраняет выбранные чаты при автообновлении через query string.
- На узких экранах панели складываются вертикально.
- Оба выбранных чата загружаются параллельно через одну авторизованную Telegram-сессию на HTTP-запрос; одинаковые chat
  id не запрашиваются повторно.
- Ошибка или таймаут одной истории показывается только в её панели и не скрывает успешно загруженную соседнюю панель.
- После успешной загрузки временный сбой следующего auto-refresh сохраняет последние сообщения обеих панелей.
- Настроенные `PINNED_CHATS` остаются доступны для выбора без зависимости от полного списка Telegram-диалогов.

## Non-Goals

- Отправка сообщений из интерфейса.
- Редактирование, удаление, пересылка, реакции.
- WebSocket или SPA.
- Больше двух панелей.
- Поиск по тексту сообщений.
